这次主页从 Jekyll/Chirpy 切换到了 XHBlogs 模板。新版本保留原来的课程笔记和 PDF 资料，同时增加了首页卡片、项目展示、照片墙、杂谈、说说、音乐卡片、AI 助手和评论预留入口。

主部署环境切换为 Vercel，因为这个模板包含 Next.js API 路由，GitHub Pages 不再适合作为主要运行环境。
