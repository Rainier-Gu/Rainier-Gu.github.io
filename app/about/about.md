你好，我是 **RainierGu**。

这个主页是我的学习档案馆，用来整理物理课程、经济学课程、科研阅读、技术实践和项目资料。相比只保存最终结论，我更希望留下推导过程、踩坑记录、材料链接和可以复用的 PDF 文档。

## 主要内容

- **物理学习**：普通物理实验、计算物理、课程笔记与实验报告整理。
- **经济学学习**：中级微观、中级宏观、数理经济学等课程资料。
- **科研与技术**：阅读笔记、代码实践、工具配置与项目进展。
- **资料归档**：把 PDF、图片、文章和项目入口放到一个更容易检索的位置。

## 当前站点

本站基于 **Next.js + XHBlogs 模板** 改造，部署在 Vercel，并保留 GitHub 仓库作为版本管理入口。

如果你正在阅读某篇课程资料或 PDF，请把它当作学习参考而不是标准答案；课程要求、实验条件和评分标准可能随年份变化。

欢迎交流，也欢迎提醒我修正文章中的错误。
